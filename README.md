# 모아모아

알바 근무와 급여를 모아 보는 개인 장부입니다. 데이터는 이 기기의 브라우저에만 저장되고, 서버나 데이터베이스는 없습니다.

https://guruum819.github.io/moamoa/

## 아이폰

사파리에서 공유 → 홈 화면에 추가를 누르면 앱처럼 열립니다.

애플 캘린더와 맞추려면 설정에서 GitHub classic 토큰(`gist` 권한만)을 넣고 캘린더 피드를 올린 뒤, 그 주소를 **구독**하세요. 구독은 한 번이면 됩니다. 같은 일정은 덮어쓰고, 앱에서 지운 근무는 새로고침 뒤 캘린더에서도 빠집니다. `.ics` 파일을 반복해서 추가하면 일정이 겹칠 수 있습니다.

## 개발

```bash
npm install
npm test
npm run dev
npm run build
```
